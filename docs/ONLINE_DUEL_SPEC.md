# 하찮냥 온라인 냥탈전 Spec

## 한 줄 가치

지금 접속한 사람과 같은 고양이를 동시에 쫓아, 먼저 잡은 한 명만 이긴다.

## 제품 구조

- `레벨 1~10`: 혼자 패턴을 배우고 고양이와 카드를 수집하는 캠페인
- `오늘의 한 판`: 모두가 같은 하루 시드로 개인 최고점을 줄이는 재방문 모드
- `온라인 냥탈전`: 동시 접속자 또는 최근 플레이 고스트와 겨루는 반복 플레이 모드
- `친구 냥탈전`: 2분짜리 일회용 초대장으로 특정 친구와 같은 시각에 시작하는 비공개 승부
- `토스 전체 랭킹`: 온라인 승리가 아니라 검증 가능한 개인 점수 기록을 비교하는 플랫폼 리더보드

온라인 대전은 캠페인을 대체하지 않는다. 홈에서 가장 생동감 있는 카드로 노출하되, 첫 플레이 사용자는 기존 추천 레벨을 그대로 시작할 수 있다.

## 한 판의 흐름

1. 홈의 `지금 붙기`를 누른다.
2. 익명 게임 세션을 만들고 매칭 큐에 들어간다.
3. 3초 안에 상대가 있으면 실시간 1:1, 없으면 최근 실제 기록을 가진 고스트와 매칭한다.
4. 양쪽에 같은 `level`, `seed`, `startsAt`을 전달한다.
5. `3 · 2 · 1 · 잡아!` 뒤 15초, 기회 5번으로 플레이한다.
6. 첫 유효 포획 요청 하나만 서버가 원자적으로 승자로 확정한다.
7. 결과에서 시간 차, 상대 이름, 재대결과 도발 공유를 제공한다.
8. 상대가 먼저 잡으면 결과표로 즉시 끊지 않고, 2.2초 동안 상대 이름·기록·상황별 자동 도발을 크게 보여준 뒤 결과로 이어간다. 자동 생성 문구는 `상대 손 번역기`로 표시해 실제 채팅과 혼동하지 않게 한다.

## 친구 초대전

1. 홈이나 대전 결과에서 `친구 불러 붙기`를 누른다.
2. 서버는 원문을 저장하지 않는 2분짜리 일회용 토큰을 발급한다.
3. 링크를 연 상대에게 방장 이름과 `도전 받기`를 보여준다. 링크 조회만으로는 입장시키지 않는다.
4. 첫 수락자 한 명만 서버 잠금으로 좌석을 얻는다. 방장 본인, 세 번째 사용자, 만료·취소된 링크는 구분해서 안내한다.
5. 수락 시 서버가 `level`, `seed`, 5초 뒤의 `startsAt`을 생성하고 양쪽에 같은 매치를 전달한다.
6. 방장은 Realtime과 폴링 폴백으로 상대 입장을 감지한다. 공유창 때문에 앱이 잠시 가려져도 대기방은 유지한다.
7. 결과의 도발·복수 CTA는 단순 홍보 링크가 아니라 새 초대방을 만들어 실제 다음 판으로 이어진다.
8. 홈에서는 `바로 붙기`와 `친구 지목전`을 동등한 모드 카드로 노출한다. 친구 지목전은 링크 초대·같은 고양이·동시 시작이라는 차이를 진입 전에 설명한다.

초대전은 친구끼리 반복해서 점수를 만들 수 있으므로 주간 리그와 랭크 연승에서 제외한다. 대신 `친구전 N승 N패`를 별도 전적으로 제공한다.

## UX 원칙

- 대기 화면은 로딩 화면이 아니라 짧은 긴장 구간이다.
- `접속 중 N명`은 Realtime Presence가 연결됐을 때만 사실대로 표시한다.
- 상대가 없어도 3초 이상 기다리게 하지 않는다.
- 서버 연결 실패는 캠페인을 막지 않으며 `혼자 연습하기`로 즉시 복구한다.
- 실시간 상대와 고스트를 결과에서 명확하게 구분한다.
- 대전 중 앱이 백그라운드로 가면 해당 판은 포기 처리하고 오디오를 멈춘다.

## 공정성

- 서버가 경기 시드와 시작 시각을 만든다.
- 동일 시드로 동일한 기본 움직임을 재현한다. 손을 읽는 패턴은 각 플레이어 입력에 반응한다.
- 포획은 시작 후 450ms~15초, 시도 1~5회, 정확도 0~100만 허용한다.
- 승자 확정은 조건부 단일 UPDATE로 처리한다.
- 클라이언트 점수는 완전한 치팅 방지가 아니다. 금전성 보상은 연결하지 않는다.

## 데이터 최소화

- Supabase 익명 Auth ID와 게임용 랜덤 닉네임만 사용한다.
- 토스 사용자 해시, 연락처, 실명은 외부 서버로 전송하지 않는다.
- 큐는 20초, 매치·고스트 기록은 주간 리그 정산에 필요한 8일만 유지하고 개인 누적 전적만 남긴다.

## 성공 지표

- 온라인 카드 클릭률
- 매칭 성공률과 고스트 전환율
- 매칭 시작부터 결과까지 완료율
- 재대결률
- 대전 결과 공유율
- 초대장 생성 대비 수락률과 초대전 완료율

## 주간 냥손 리그

- 실시간 상대 승리는 3점, 최근 기록 고스트 승리는 1점이다.
- 점수가 같으면 해당 주 최속승이 빠른 순으로 정렬한다.
- 고스트만 만나는 시간에도 성장할 수 있지만, 실제 사람과의 승부를 더 크게 보상한다.
- 친구 초대전은 별도 전적으로만 남기고 주간 점수에 포함하지 않는다.

## 출시 게이트

- 두 브라우저에서 동일 경기·동일 시작 시각 확인
- 동시에 잡아도 승자가 한 명만 기록됨
- 상대 이탈·오프라인·중복 탭 복구
- 초대 링크 미리보기만으로 좌석을 차지하지 않음, 첫 수락자만 입장, 제3자·만료·취소 처리 확인
- RLS 및 SECURITY DEFINER 함수 보안 검토
- Supabase 보안·성능 Advisor 경고 0건
- 웹, 모바일 뷰, Apps in Toss `.ait` 회귀 검증
