# 하찮냥 온라인 냥탈전 Spec

## 한 줄 가치

지금 접속한 사람과 같은 고양이를 동시에 쫓아, 먼저 잡은 한 명만 이긴다.

## 제품 구조

- `레벨 1~10`: 혼자 패턴을 배우고 고양이와 카드를 수집하는 캠페인
- `오늘의 한 판`: 모두가 같은 하루 시드로 개인 최고점을 줄이는 재방문 모드
- `온라인 냥탈전`: 지금 동시 접속한 실제 사용자끼리만 겨루는 랭크 승부
- `친구 냥탈전`: 첫 고양이를 고르고 친구와 한쪽이 나갈 때까지 라운드를 이어가는 비공개 세션
- `토스 전체 랭킹`: 온라인 승리가 아니라 검증 가능한 개인 점수 기록을 비교하는 플랫폼 리더보드

온라인 대전은 캠페인을 대체하지 않는다. 홈에서 가장 생동감 있는 카드로 노출하되, 첫 플레이 사용자는 기존 추천 레벨을 그대로 시작할 수 있다.

## 한 판의 흐름

1. 홈의 `지금 붙기`를 누른다.
2. 익명 게임 세션을 만들고 매칭 큐에 들어간다.
3. 실시간 상대가 나타날 때까지 큐를 유지하며 고스트를 생성하지 않는다. 오래 걸리면 친구 초대와 혼자 연습으로 빠질 수 있다.
4. 양쪽에 같은 `level`, `seed`, `startsAt`을 전달한다.
5. `3 · 2 · 1 · 잡아!` 뒤 15초, 기회 5번으로 플레이한다.
6. 첫 유효 포획 요청 하나만 서버가 원자적으로 승자로 확정한다.
7. 결과에서 시간 차, 상대 이름, 재대결과 도발 공유를 제공한다.
8. 상대가 먼저 잡으면 결과표로 즉시 끊지 않고, 2.2초 동안 상대 이름·기록·상황별 자동 도발을 크게 보여준 뒤 결과로 이어간다. 자동 생성 문구는 `상대 손 번역기`로 표시해 실제 채팅과 혼동하지 않게 한다.

## 친구 초대전

1. 홈이나 대전 결과에서 `친구 불러 붙기`를 누르고 첫 라운드의 고양이를 10마리 중 고른다.
2. 서버는 원문을 저장하지 않는 2분짜리 일회용 토큰을 발급한다.
3. 링크를 연 상대에게 방장 이름과 `도전 받기`를 보여준다. 링크 조회만으로는 입장시키지 않는다.
4. 첫 수락자 한 명만 서버 잠금으로 좌석을 얻는다. 방장 본인, 세 번째 사용자, 만료·취소된 링크는 구분해서 안내한다.
5. 수락 시 서버가 지속 세션과 첫 매치를 함께 만들고, 선택된 `level`, 동일 `seed`, 5초 뒤의 `startsAt`을 양쪽에 전달한다.
6. 방장은 Realtime과 폴링 폴백으로 상대 입장을 감지한다. 공유창 때문에 앱이 잠시 가려져도 대기방은 유지한다.
7. 한 라운드가 끝나면 서버가 세션 점수와 다음 선택권을 원자적으로 갱신한다. 패자가 다음 고양이를 선택하고, 무승부면 직전 선택권의 반대편이 고른다.
8. 선택 제한은 15초다. 제한 시간이 지나면 어느 참가자든 직전 고양이로 다음 라운드를 시작시켜 교착을 막는다.
9. 같은 방과 상대를 유지하면서 `고양이 선택 → 동시 시작 → 결과`를 어느 한쪽이 나갈 때까지 반복한다. 새 링크는 필요 없다.
10. 앱 새로고침은 세션 ID로 복구하고 Realtime과 폴링을 함께 사용한다. 명시적 나가기는 즉시 방을 닫고, 45초 이상 heartbeat가 없는 참가자는 이탈로 처리한다.
11. 홈에서는 `바로 붙기`와 `친구 지목전`을 동등한 모드 카드로 노출한다. 친구 지목전은 패자 선택·무제한 라운드라는 차이를 진입 전에 설명한다.

## 배틀 이름

- 앱 첫 실행은 막지 않는다. 사용자가 `바로 붙기`, `친구 지목전`, `도전 수락`을 처음 실행할 때 현재 랜덤 이름을 미리 채운 바텀시트에서 한 번만 확인한다.
- 이름은 한글·영문·숫자와 공백·밑줄·하이픈으로 2~10자이며, 서버에서도 같은 규칙과 예약어를 검증한다.
- 확인한 이름은 익명 Auth 사용자 프로필에 저장하고 홈에서 수정할 수 있다. 진행 중인 승부의 이름은 시작 시점 스냅샷을 유지한다.
- 최신 이름은 다음 매치, 초대, 결과, 공유 문구와 주간 리그에 반영한다. 분석 이벤트에는 실제 이름을 보내지 않고 길이와 입력 방식만 기록한다.
- 사용자 입력을 취소하면 원래 보던 홈이나 초대 화면에 남는다. 랜덤 이름 다시 뽑기를 제공해 입력 부담을 낮춘다.

초대전은 친구끼리 반복해서 점수를 만들 수 있으므로 주간 리그와 랭크 연승에서 제외한다. 대신 `친구전 N승 N패`를 별도 전적으로 제공한다.

## UX 원칙

- 대기 화면은 로딩 화면이 아니라 짧은 긴장 구간이다.
- `접속 중 N명`은 Realtime Presence가 연결됐을 때만 사실대로 표시한다.
- 실제 상대가 늦으면 6초 뒤 `친구 불러오기`, `조금 더 기다리기`, `혼자 연습하기` 선택지를 제공한다.
- 서버 연결 실패는 캠페인을 막지 않으며 `혼자 연습하기`로 즉시 복구한다.
- 자동 생성 상대나 과거 기록을 실제 사용자처럼 노출하지 않는다.
- 대전 중 앱이 백그라운드로 가면 해당 판은 포기 처리하고 오디오를 멈춘다.

## 공정성

- 서버가 경기 시드와 시작 시각을 만든다.
- 동일 시드로 동일한 기본 움직임을 재현한다. 손을 읽는 패턴은 각 플레이어 입력에 반응한다.
- 포획은 시작 후 450ms~15초, 시도 1~5회, 정확도 0~100만 허용한다.
- 승자 확정은 조건부 단일 UPDATE로 처리한다.
- 클라이언트 점수는 완전한 치팅 방지가 아니다. 금전성 보상은 연결하지 않는다.

## 데이터 최소화

- Supabase 익명 Auth ID와 게임용 랜덤 닉네임만 사용한다.
- 토스 사용자 해시, 연락처, 실명은 외부 서버로 전송하지 않는다.
- 큐는 20초, 매치 기록은 주간 리그 정산에 필요한 8일만 유지하고 개인 누적 전적만 남긴다. 친구 세션은 참가자만 조회한다.

## 성공 지표

- 온라인 카드 클릭률
- 실제 사용자 매칭 성공률과 6초 이후 친구 초대 전환율
- 매칭 시작부터 결과까지 완료율
- 친구 세션당 라운드 수와 자발적 종료 시점
- 대전 결과 공유율
- 초대장 생성 대비 수락률과 초대전 완료율

## 주간 냥손 리그

- 랜덤 실시간 상대 승리만 3점이다.
- 점수가 같으면 해당 주 최속승이 빠른 순으로 정렬한다.
- 실제 사용자가 없는 시간에는 점수를 만들지 않는다. 친구 세션과 혼자 연습은 랭크에 영향을 주지 않는다.
- 친구 초대전은 별도 전적으로만 남기고 주간 점수에 포함하지 않는다.

## 출시 게이트

- 두 브라우저에서 동일 경기·동일 시작 시각 확인
- 동시에 잡아도 승자가 한 명만 기록됨
- 상대 이탈·오프라인·중복 탭 복구
- 3라운드 이상 같은 세션에서 고양이 선택·점수 누적·패자 선택권 확인
- 선택 시간 초과 시 직전 고양이 자동 진행, 새로고침 시 현재 세션 복구
- 초대 링크 미리보기만으로 좌석을 차지하지 않음, 첫 수락자만 입장, 제3자·만료·취소 처리 확인
- RLS 및 SECURITY DEFINER 함수 보안 검토
- Supabase 보안·성능 Advisor 경고 0건
- 웹, 모바일 뷰, Apps in Toss `.ait` 회귀 검증
